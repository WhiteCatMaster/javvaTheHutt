# javvaTheHutt
javva the hutt is a student project taking base in JLox interpreter , it doesnt look to be usefull at all, neither fun to use, just fun to program ( for me ) 

# Scanner
the scanner is made in a funny way, apart from that i more or less used Lox token types, adding extras as the dollar, backslash... or others like nor, xor, or xnor, multilingual is impelmented too, I have to do some research but i didn't see any programming language that works this way, it is suppose to be funny looking and not usable at all, so I didnt really complicate the things in the way I change the language, but if BTW someone thought about a better implementation , im open to new ideas.
